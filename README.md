# SC-100 Study Lab

Personal SC-100 practice site built from 360 supplied question screenshots. The question bank is split into four pages of 100, 100, 100, and 60 questions, with immediate answer feedback and browser-local progress.

The written explanation in each screenshot determines the graded answer when it disagrees with the marked option. Question images are included in `images/`.

This repository is configured for GitHub Pages through `.github/workflows/pages.yml`. In repository settings, select **GitHub Actions** as the Pages build and deployment source.
